# SEO Todo — فروشگاه آروین

## حیاتی (بدون این‌ها ایندکس درست نمی‌شود)

- [ ] Meta description برای همه صفحات عمومی (خانه، محصول، بلاگ، دسته‌ها، درباره، تماس، FAQ)
- [ ] Open Graph + Twitter Card (عنوان، توضیح، تصویر، URL)
- [ ] Canonical URL برای جلوگیری از محتوای تکراری (`?site=mobile/desktop` و پارامترهای فیلتر)
- [ ] `robots.txt`
- [ ] Sitemap XML (محصولات منتشرشده، پست‌های بلاگ، صفحات ثابت)
- [ ] `{% block extra_head %}` در `base-desktop` و `base-mobile` برای متاهای اختصاصی هر صفحه

## ساختار URL و ایندکس‌پذیری

- [ ] اسلاگ برای پست‌های بلاگ به‌جای `/blog/123/`
- [ ] صفحه لندینگ واقعی برای دسته‌بندی محصولات با اسلاگ (الان فقط `?category_id=` است)
- [ ] صفحه‌بندی قابل کراول با لینک `<a href="?page=N">` به‌جای دکمه JS
- [ ] `noindex` برای سبد، چک‌اوت، پنل کاربری، جستجوهای خالی/ناقص
- [ ] کوتاه‌کردن URL محصول (اختیاری): `/shop/product/<slug>/` به‌جای `.../detail/`

## Schema و محتوای on-page

- [ ] JSON-LD محصول (Product: نام، قیمت، موجودی، تصویر)
- [ ] JSON-LD مقاله برای بلاگ
- [ ] BreadcrumbList (الان فقط UI است، و در PDP/بلاگ اصلاً نیست)
- [ ] FAQPage schema برای صفحه سوالات متداول
- [ ] `<h1>` واضح در صفحه خانه
- [ ] عنوان داینامیک لیست محصولات وقتی دسته/جستجو فعال است
- [ ] پر کردن `alt` خالی تصاویر (مثلاً تامب‌های PDP)
- [ ] اصلاح altهای اشتباه برند در صفحه درباره (`Noorbanoo Life`)

## محتوا و پنل ادمین

- [ ] فیلدهای SEO در ادمین: `meta_title`، `meta_description`، `og_image` برای محصول/پست/صفحات ثابت
- [ ] استفاده از `brief_description` محصول به‌عنوان پیش‌فرض meta description
- [ ] اتصال لینک دسته‌ها در صفحه محصول به صفحه دسته واقعی (الان `#` است)

## فنی / سرعت / امنیت

- [ ] بررسی `Cache-Control: no-store` روی صفحات عمومی (الان همه HTML بدون کش‌اند)
- [ ] `lazy` + `width`/`height` برای تصاویر مهم PDP
- [ ] HTTPS redirect / HSTS / کوکی امن (اگر در سرور/nginx نیست)
- [ ] ثبت سایت در Google Search Console + Bing و ارسال sitemap
- [ ] اتصال Analytics / اندازه‌گیری Core Web Vitals
