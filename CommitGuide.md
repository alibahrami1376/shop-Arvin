# Commit Guide

## Format

```text
<type>(<scope>): <message>
```

### Types

- `feat` : New feature
- `fix` : Bug fix
- `refactor` : Code improvement (no behavior change)
- `docs` : Documentation
- `style` : Formatting
- `test` : Tests
- `perf` : Performance improvement
- `chore` : Maintenance

## Examples

```bash
feat(accounts): add user roles
fix(cart): calculate subtotal correctly
refactor(order): simplify checkout flow
docs: update README
test(products): add model tests
chore: update dependencies
```

## Rules

- Use English.
- Use imperative verbs (`add`, `fix`, `remove`, `update`).
- First letter lowercase.
- No period (`.`) at the end.
- Keep it short.
